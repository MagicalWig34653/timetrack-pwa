# timetrack-pwa

Teil von Timetrack, AGPL-3.0-only. Arbeitsmittelpunkt: [../timetrack-backend](../timetrack-backend).
Konzept, Agent-Aufträge und API-Verträge werden im Backend verwaltet.

## Lokal starten

```sh
npm ci
npm run check
npm run build
npm run dev
```

Aktueller Implementierungs-/Prüfstand: [docs/STATUS.md](docs/STATUS.md).

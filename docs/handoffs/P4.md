# Handoff P4 (PWA): Systeminfo für Mitglieder

Stand: 19.10.2026. Branch `p4-system-info-members`, nicht gemergt. Gegenstück: Backend S1b (Vertrag 0.23.0).

`GET /api/v1/system/info` liefert normalen Mitgliedern nur Versionsfelder; `database`, `schemaMigrations`, `migrationsPending`, `uptimeSeconds`, `replicaId` fehlen (Schlüssel fehlen ganz) und kommen nur für Admins.

- `types.ts`: diese fünf Felder sind optional.
- `VersionInfo.svelte`: Zeilen Datenbank, Migrationen, Laufzeit, Replikat nur, wenn vorhanden.
- `info.ts`: `supportText` hängt die Datenbank nur an, wenn vorhanden; `formatUptime` gibt für nicht endliche Werte „–“ zurück (nie NaN). Abweichungsprüfung und „Angaben kopieren“ funktionieren unverändert.
- Mock: `GET /system/info` liefert die Admin-Variante für Admin-Konten, sonst die Mitglieder-Variante.
- Tests: Unit (Mitglied und Admin in `info.test.ts`), Mock-E2E „members see only version fields“ in `e2e-mock/version.spec.ts` (entfernt die Admin-Schlüssel per Route; die Admin-Variante prüfen die bestehenden Fälle).

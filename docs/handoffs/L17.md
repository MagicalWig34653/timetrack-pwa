# Handoff L17 – Modulschalter in der PWA und Doku-Auffrischung

Branch `l17-modules`. Grundlage: ADR-0012 (verbindlich), Vertrag v0.9.0. Backend nur gelesen.

## Umgesetzt
- Typen/Client: `ModuleKey/ModuleStatus/ServerModule`, `listModules`, `putMyModules`, `getServerModules`, `putServerModules`; `404 module_disabled` ruft einen Handler auf, der den Store aktualisiert. Deutsche Texte `src/lib/i18n/de-modules.ts` (inkl. `error.module_disabled`, `error.module_locked`).
- Store `src/lib/modules/store.svelte.ts` (Laden im `(app)`- und `oauth`-Routenwächter, 404/501 = alles an, Zurücksetzen beim Abmelden). Klassifikation `src/lib/modules/map.ts`, Navigationslisten `src/lib/nav.ts`.
- Ausblenden: Hauptnavigation, Einstellungs-Navigation, Dashboard (Berichtsheft-Karte, Vorschlagshinweis, kein `listSuggestions`-Aufruf), Benachrichtigungs-Kategorien (report_gap, document_submission, pending_suggestions), Anhänge im Abwesenheitsformular und in Berichtsheft-Quellen, Kalenderlink im Importergebnis. Gesperrte Routen: `ModuleDisabled.svelte` im App-Layout, `/oauth/consent` eigene Ansicht.
- Seiten `/settings/modules` und `/admin/modules` (Warndialog). Der Dialog ist ein einfaches Inline-`alertdialog`-Element (keine Fokusfalle).
- Mock `mock/modules.ts`: Regeln server && Konto, 409 `module_locked`, zentraler Guard vor den Gruppen-Handlern (404 `module_disabled`), Hook `POST /api/v1/mock/modules {locked, server}`, Env `MOCK_MODULES_DISABLED`; bei planning=aus fließen Abwesenheiten/Feiertage nicht in `time/days`.
- Flaky-Test `TimerCard … double click` repariert: wartet auf `aria-busy` statt 30 ms Schlaf; 10 aufeinanderfolgende `npm test` grün.
- Doku: README, AGENTS, CLAUDE, STATUS neu geschrieben.

## Prüfung
check 0/0; `npm test` 455 (10 Läufe in Folge grün); build; `test:e2e:mock` mit neuer Spec grün; `test:e2e:pwa` 6 grün; Screenshots `/settings/modules` und `/admin/modules` bei 390 px dunkel gesichtet, kein horizontales Scrollen. Echt-Backend-Lauf: siehe Abschlussbericht.

## Offen / Annahmen
- Ob `automation/events` und MCP serverweit vs. kontobezogen 404 liefern, ist im Mock vereinfacht.
- Benachrichtigungskategorien werden nur ausgeblendet, wenn das zugehörige Modul aus ist (Zuordnung report_gap→reports, document_submission→planning, pending_suggestions→automation: Annahme aus ADR-0012).
- Echt-Backend-E2E für Module (Schalter, 404-Gruppen) fehlt noch; nach C20-Merge ergänzen.

# Übergabe L5 – Integration Zeiterfassung und Kurzbefehle

Branch `l5-time-integration` (nicht gepusht). Backend nur gelesen, nicht verändert. Code/Tests englisch, UI deutsch.

## Geändert

- `e2e/global-setup.ts`: startet zwei Backend-Instanzen mit je eigener SQLite-DB (Stage 1 auf `E2E_PORT`, Standard 18090; Stage 2 auf
  `E2E_TIME_PORT`, Standard `E2E_PORT`+1). Grund: `bootstrap-admin` funktioniert nur für das erste Konto einer DB (409 danach), die
  neue Spec darf nicht vom Stage-1-Konto abhängen. Port 18080 wird nie berührt.
- `e2e/helpers.ts`: `newActor(browser, credentials, baseURL?)`.
- `e2e/stage2-time.spec.ts`: 14 serielle Tests (siehe STATUS). Ereignisse nutzen je Szenario eine eigene `deviceId`, weil das Backend
  Ereignisse je Gerät und Ort nach `occurredAt` ordnet (ältere später gesendete Ereignisse -> `needs_review`).
- UI-Fixes: `time/[date]` füllt Notiz und Markierungs-Gutschrift aus `DayEvaluation.note/markCreditSeconds` (v0.2.1; Typen ergänzt);
  `settings/account-time` zeigt die Anfangsstand-Maske auch, wenn `accountStart` schon durch das erste Modell gesetzt ist (Server: 409 `opening_exists`);
  `suggestions`: `suggestion_resolved` (409) übersetzt, Liste wird neu geladen; Geräte-Hilfetext verweist auf `docs/SHORTCUTS.md`.
- `docs/SHORTCUTS.md` neu.

fehlende Meldung `suggestion_resolved`.
